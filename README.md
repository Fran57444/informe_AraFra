# Informe AraFra

Aplicación web de análisis jurídico y técnico del incidente SUNBURST en el contexto chileno.

- Presenta secciones de resumen, marco legal, delitos, comparación regulatoria, responsabilidades, datos personales, conclusiones y prompts.
- Incluye modo claro/oscuro y navegación interna entre secciones.
- Construido con React, Vite y Tailwind CSS.
- Usa componentes React y diseño responsive.

https://informe-arafra.vercel.app/
